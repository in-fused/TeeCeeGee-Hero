# PackFinder API

Production-grade API scaffold for locating and tracking availability signals for Pokémon and One Piece sealed products.

## Principles
- **No mock data**
- **Explicit data provenance**
- **Fail loudly when data is unavailable**
- **Frontend-ready API**

## Stack
- TypeScript
- Fastify
- PostgreSQL + PostGIS

## Getting Started (later)
This scaffold is safe to upload to GitHub as-is. Environment setup is documented in RUNBOOK.md.
